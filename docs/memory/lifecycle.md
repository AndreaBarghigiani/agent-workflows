# Custom capture lifecycle retired

The custom verification runner, milestone fence, Stop handler, local journals,
receipt queue and replay runtime have been removed in favor of native Basic Memory
skills. No new consumer hook setup is required.

Read the [native lifecycle guide](lifecycle-guide.md) and [migration guide](migration.md).
Earlier design and bounded verification remain in Git history and stage reports.
Those historical results do not prescribe the current setup or prove native
client behavior after migration.
